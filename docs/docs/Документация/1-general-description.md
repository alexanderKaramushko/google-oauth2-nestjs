# 1. Общее описание

`google-oauth2-nestjs` - SSO-сервис на базе NestJS, который реализует аутентификацию пользователей через Google OAuth 2.0 и Google Identity.

Сервис отвечает за запуск OAuth-флоу, обработку редиректа от Google, проверку или создание пользователя и выдачу JWT для дальнейшей работы защищенных роутов.

Сервис используется как точка входа для внешних приложений, которым нужна единая авторизация через аккаунт Google и проверка пользовательского `id_token` на защищенных ручках.

Перед началом работы в Google Console регистрируется OAuth-приложение, а сервис получает `CLIENT_ID`, `CLIENT_SECRET`, `OAUTH_CALLBACK_HOST`, `OAUTH_STATE_SECRET` и карту клиентских приложений `OAUTH_CLIENT_APPS`.

Подробный runtime-алгоритм авторизации и проверки токена вынесен в раздел [Бизнес-правила](./business-processes).
